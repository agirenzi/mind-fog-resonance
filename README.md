# Mind Fog Resonance

Original procedural generative audio space. Zero-grid ambient resonance with live visualization and AudioWorklet PCM capture.

## Run it

Open `index.html` in any modern browser, or enable GitHub Pages on the `main` branch for a live URL.

- Click **Initiate** to start the resonance and arm WAV capture
- Switch presets or move Density / Brightness
- Finish or Suspend to export a 16-bit WAV

No external models or APIs required.
